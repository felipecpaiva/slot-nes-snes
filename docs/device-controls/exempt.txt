# Exemptions for scripts/device-controls.sh: libretro joypad ids a core polls that no device button is meant
# to answer. One per line: PLATDIR id reason
#   PLATDIR  the Games/ folder name (SNES, CPS1, NEOGEO, VB ...), case does not matter
#   id       the libretro joypad id (0 B, 1 Y, 2 SELECT, 3 START, 4-7 UP DOWN LEFT RIGHT, 8 A, 9 X, 10 L, 11 R,
#            12 L2, 13 R2, 14 L3, 15 R3)
#   reason   free text, the ADR or note that says why (see ADR 0108)
# Lines starting with # are ignored. Ids 14 and 15 are already ignored on every platform but VB.
