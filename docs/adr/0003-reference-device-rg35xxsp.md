# 0003. Use the Anbernic RG35XXSP as the reference device

- Status: Superseded by [0021](0021-reference-device-rg34xxsp.md)
- Date: 2026-10-11
- Deciders: maintainer (Felipe Paiva)
- Related: [PLAN.md](../PLAN.md) Context

## Context

The plan needed one device to test on and to size the picture for. The request was to use the
maintainer's own handheld as the reference and test device.

## Decision

The Anbernic RG35XXSP is the reference and test device.

## Consequences

- The 640x427 window and GBA SP bezel decision ([0005](0005-gba-sp-bezel-on-rg35xxsp.md)) was made
  for this device.
- Superseded on 2026-10-12: the maintainer's device is an RG34XXSP
  ([0021](0021-reference-device-rg34xxsp.md)).
